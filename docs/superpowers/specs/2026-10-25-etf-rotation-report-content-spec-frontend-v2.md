## 1. 文档用途与阅读路径

本文是报告的设计输入：每一章说明该章展示什么内容，随后给出该章的图表与表格清单，最后对重点图表说明画什么、怎么读、必须标注什么。

| 读者 | 想确认的事 | 必须能直达 |
|---|---|---|
| 配置决策者 | 收益与风险画像、回撤体验、成本与稳健性 | 核心指标概览、回撤体验、稳健性摘要 |
| 策略研究者 | 规则是否按设计执行、有没有隐藏风险 | 决策审计、归因、暴露、事件表 |
| 代码/数据审阅者 | 数字是否可信、能否复现 | 口径说明、对齐自检、数据质量、run 元信息、明细表 |
| 外部评审 | 与研报的差距是否可解释 | 差距数字对照、已知问题清单 |

## 2. 展示与标注约定

所有章节必须遵守，避免同一指标出现多个数值。

1. **年化收益**：统一展示日历日 CAGR。若同时给出算术年化，必须显式标注「算术」，且不得与 CAGR 混用。当前三种口径分别约为 9.61% / 9.99% / 10.21%，报告只允许出现被标注的那一个。
2. **唯一数值**：同一指标在全报告只有一个数值、一个口径；波动 / Sharpe / Sortino 也只展示其唯一的展示口径，不得并列多个版本。
3. **度量对象**：金额与百分比保留 2 位小数，比率保留 2 位，金额类字段保留 4 位。
4. **成本**：默认单边 8bp。累计费用以引擎口径为准，逐笔估算只作对照，两者不一致时必须同时列出。
5. **基准**：只保留沪深300。等权全池基准本期不展示。
6. **超额**：同时给两种并标注——几何超额 = CAGR(策略) − CAGR(基准)；算术超额 = 年化算术均值之差。IR 对应算术超额 / 跟踪误差。
7. **权重口径**：`weights.parquet` 是目标权重；`holdings.csv` 是引擎实际持仓；两者不可混用，偏差单独成图（X01）。
8. **事后指标**（如事件后 5/20 日收益）只用于复盘评价，必须标注「事后，不参与决策」。
9. **颜色语义**固定：正 / 盈利绿，负 / 亏损红，策略蓝，基准灰，警示橙。
10. **不允许手填**：页面上任何数字都必须来自报告产物；前端不得写死数值或补写结论。

**这一章展示什么**

### 3.3 C3 决策审计

**这一章展示什么**

目的：这是「为什么这样调仓」的主体，必须支持**任意一天**的追溯。展示顺序固定：联动时间轴 → 事件表 → 事件详情 → 候选池快照 → 单标的信号 → 全量决策日记表 → 阶段归因。

1. **联动时间轴（D04）**：一张多轨图，同时承载市场状态、风险预算、仓位、回撤、TOP10 持仓与事件标记；下方配 **市场状态区间表（D10）** 与 **风险预算分段表（D11）**，把两条轨道落成可筛选的数字。
   - 市场状态轨道：regime 色带 + comp_score（±0.30 / −0.35 阈值线）+ 当日创业板趋势 / 波动；
   - 风险预算轨道：risk_scale、vol_scale_risk、risk_budget；
   - 总仓位与现金、回撤；
   - **TOP10 持仓轨道**：每日权重前 10 的标的仓位随时间变化，标出新进 / 退出 TOP10；
   - 事件标记（来自 D01）。
2. **事件表（D01，全量，可筛选 / 排序 / 导出）**：日期、事件类型（换仓 / 过热清零 / 波动上限缩放 / 防守重选 / 跨资产腿切换）、当日 regime、换手、前三大权重变动、触发规则、事后 5/20 日收益（标注事后）；配 **事件时间轴（D02）**。
3. **事件详情卡（D03）**：选中某日后按时间顺序展示四步
   1. **事前持仓**（T 日收盘）：实际持仓 TOP N、类别构成、现金、总仓位；
   2. **目标变动**（T 日信号）：目标权重 vs 事前持仓 → 新增 / 加仓 / 减仓 / 清仓名单 + Δw；
   3. **实际成交**（T+1）：逐笔成交的标的、方向、价格、数量、金额、费用，标记顺延 / 停牌 / 部分成交；
   4. **事后持仓**（T+1 收盘）：成交后的实际持仓，及与目标的偏差（口径见 X01）。
   市场状态与风险预算不再展开在卡内，改为卡片顶部一行摘要（regime、risk_budget 两个值）+ 跳转 D04 对应日期。
4. **候选池快照（D05）**：任一日 top 30 候选的 score / rank / 是否保留 / 剔除原因。
5. **单标的信号（D06）**：m21/m60、score、zbias、close vs llt80（过热阈值线）、weight、status，事件点打标；**整行宽度展示，不与其他图并排**。
6. **全量决策日记表（D08）**：24 列可筛选，作为审计底稿。
7. **阶段归因瀑布（D09）**：候选 → 去重 → 过热 → 跨资产 → 防守 → 迟滞 → 波动上限 → 最终。

**重点图表说明**

#### D04 联动时间轴

- 一张多轨图，轨道从上到下：
  1. **市场状态**：regime 色带（牛 / 震荡 / 熊）+ comp_score 折线，标 ±0.30 / −0.35 阈值线；悬停显示当日创业板趋势与波动；
  2. **风险预算**：risk_scale、vol_scale_risk、risk_budget 三条线（同一 0–1 量纲）；
  3. **总仓位与现金**：堆叠面积；
  4. **回撤**：自上向下的面积；
  5. **TOP10 持仓**：每日按实际持仓权重取前 10，堆叠面积；其余合并为「其他」；新进 / 退出 TOP10 的日期打标；
  6. **事件标记**：来自 D01。
- 共享 x 轴；框选区间后其余图（P01 / P02 / R01 / D06）同步过滤。
- 必须标注：regime 判定阈值、事件类型图例、TOP10 口径（按实际持仓权重，与 X05 一致）。

#### D10 市场状态区间表

- 一行一个连续 regime 区间：起止日期、交易日数、占全样本比例、comp_score 区间（min / mean / max）、判定阈值、创业板趋势与波动摘要。
- 用途：把 D04 的色带变成可筛选、可导出的数字；点击行可把时间轴缩放到该区间。
- 必须标注：区间边界用的是信号日还是成交日。

#### D11 风险预算分段表

- 一行一个 risk_budget 档位或变化段：起止日期、天数、risk_scale、vol_scale_risk、risk_budget、触发原因（regime 切换 / 波动缩放 / 上限截断）。
- 必须标注：risk_budget = risk_scale × vol_scale_risk；若截断前后有差异，需同时给出截断前后的值。
- 用途：解释仓位上限的来源，替代原事件卡中的「预算」步骤。

#### D01 调仓事件表

- 每行一个事件，不是每天一行。事件类型：换仓（`hysteresis_held=False` 且有权重变化）、过热清零（`n_overheat_exits>0`）、波动上限缩放（`vol_cap_scale<1`）、防守重选、跨资产腿权重变化。
- 列：日期、类型、regime、当日换手、前三大权重变动（标的 + Δw）、触发规则、事后 5/20 日收益（标注事后）。
- 怎么读：先按换手排序看最大动作，再按类型筛选看规则是否按设计工作。
- 必须能跳转：任一行 → D03 详情卡。

#### D03 事件详情卡

- 四步按时间顺序排列，每步一张小表：
  1. **事前持仓**（T 日收盘）：实际持仓 TOP N、类别构成、现金、总仓位；
  2. **目标变动**（T 日信号）：目标权重 vs 事前持仓 → 新增 / 加仓 / 减仓 / 清仓名单 + Δw；
  3. **实际成交**（T+1）：逐笔成交的标的、方向、价格、数量、金额、费用；顺延、停牌、部分成交单独标记；
  4. **事后持仓**（T+1 收盘）：成交后的实际持仓，与目标的偏差（口径见 X01）。
- 卡片顶部一行摘要：regime、risk_budget，点击跳转 D04 对应日期。
- 必须标注：信号日与成交日（T / T+1），避免误读为同日。

#### D06 单标的信号

- 整行宽度展示，不与其他图并排；纵向适当拉高，保证事件点可辨。
- 五条轨道：m21 / m60、score、zbias、close vs llt80（过热阈值线）、weight 与 status。
- 事件点打标；从 D01 / D03 跳入时自动定位日期与标的。

### 3.7 C7 归因与暴露

## 4. 交互与联动（与版式无关）

1. **时间范围选择**：全局一个区间选择器，影响所有时序图；默认全区间。

3. **图 → 表**：任何聚合图（P04/P05/A02）可展开对应明细表。
4. **导出**：所有表格支持 CSV 导出；图表支持 PNG 导出。
5. **深链接**：`?date=2022-04-26` 能直达该日详情卡，便于在文档 / 聊天里引用。
6. **状态保持**：筛选条件写入 URL，刷新不丢。
7. **打印**：核心指标概览章可单独打印为一页，不依赖交互。

## 6. 展示禁忌

- 不画 3D、饼图、无对照的累计收益曲线。
- 不用双 y 轴混排不同量纲且不标注（如净值与换手）。
- 不只给热力图不给数字表。
- 不展示没有数据支撑的结论句；本报告不生成裁决、适用条件、可证伪点等人工结论（见 §7）。
- 不用「年化」一词指代三种不同算法。
- 不隐藏已知缺陷；缺陷必须出现在 C9。
