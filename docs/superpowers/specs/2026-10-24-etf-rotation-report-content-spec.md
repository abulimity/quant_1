## 0. 这份报告要解决什么

报告只回答两个问题：

1. **为什么这样调仓？** —— 任意一个调仓日，读者能从市场状态一路追到成交，中间每一步的规则、输入、输出都可核对。
2. **这套策略值不值得配？** —— 相对沪深300，收益、风险、回撤体验、成本、稳健性是否支撑一个配置决定，以及这个结论在什么条件下成立。

两个问题对应两种读法：**判决**（一屏读完，可打印）与**审计**（可筛选、可钻取、可导出）。同一份内容两种读法都要成立，不能只服务其中一种。

### 验收标准

一个没参与项目的资深读者，在不问任何人的情况下，5 分钟内能回答：

- 年化、波动、最大回撤、Sharpe、相对沪深300 的超额与 IR 各是多少？
- 最大回撤发生在什么时候、持续多久、什么时候收复？
- 收益主要来自哪类资产、哪几年？成本吃掉了多少？
- 2022 年为什么几乎空仓？某一天为什么把某个 ETF 清零？
- 换手有多高？成本翻倍会怎样？参数是否坐在悬崖上？
- 两个子区间的结论一致吗？和研报差多少、差在哪？
- 这份结果能不能复现？对应哪个 commit、哪份数据、哪组参数？

## 2. 全局口径与数字纪律

所有章节必须遵守，避免同一指标出现多个数值。

1. **年化收益**：统一用日历日 CAGR（`ffn.calc_cagr`）。若同时给出算术年化，必须显式标注「算术」，且不得与 CAGR 混用。当前三种口径分别约为 9.61% / 9.99% / 10.21%，报告只允许出现被标注的那一个。
2. **年化波动 / Sharpe / Sortino**：日收益 × √252。
3. **收益对齐**：T 日信号 → T+1 成交；归因用 `w.shift(1) × r_t`。基准收益必须与策略同日对齐，见 §7.B06 的对齐自检。
4. **成本**：默认单边 8bp；累计费用以引擎 `total_fees` 为准，逐笔估算只作对照，两者不一致时必须同时列出。
5. **基准**：只保留沪深300。等权全池基准本期从报告中移除（数据与代码保留）。
6. **超额**：同时给两种并标注——几何超额 = CAGR(策略) − CAGR(基准)；算术超额 = 年化算术均值之差。IR 用算术超额 / 跟踪误差。
7. **权重口径**：`weights.parquet` 是目标权重；`holdings.csv` 是引擎实际持仓；两者不可混用，偏差单独成图（X01）。
8. **事后指标**（如事件后 5/20 日收益）只用于复盘评价，必须标注「事后，不参与决策」。
9. 所有百分比保留 2 位小数，比率 2 位，金额 4 位；颜色语义固定：正/盈利绿，负/亏损红，策略蓝，基准灰，警示橙。
10. 任何一个数字都必须能指回「数据文件 + 字段 + 计算模块」，不允许手填。

## 4. 内容大纲

### C0 报告头与元信息

- 标题、区间（2019-01-02 ~ 2026-07-31）、版本、生成时间
- 一行摘要：默认 open 口径、单边 8bp、候选参数
- 元信息卡：run_id、git_sha、data_snapshot_id、execution、数据源、成本假设
- 醒目提示：本期报告相对研报为「同量级复现」，不是精确复制

### C1 判决（Verdict）

目的：让决策者在 30 秒内得到一个**有条件**的结论，而不是一堆图。

必含：

1. **一句话判决**：值 / 不值得 / 证据不足，三选一，后面必须跟「在什么条件下成立」。
2. **KPI 对照表**（策略 vs 沪深300）：年化、波动、Sharpe、Sortino、最大回撤、Calmar、几何超额、算术超额、跟踪误差、IR、beta、相关、上下行捕获、月胜率、最长水下天数。每行标注「优/劣/中性」。
3. **净值 + 回撤**双图，共享时间轴，标注最大回撤区间与修复点。
4. **三个必须知道的事实**（数字 + 一句解释），当前候选：
   - IR 仅 0.15、月胜率 51.6%：超额在统计上很薄；
   - 34% 组合波动目标全样本只触发 3 天：风险画像与设计意图不符；
   - 92% 交易日处于水下、最长 596 个交易日：持有体验是配置的主要障碍。
   > 注：IR、月胜率、超额、beta、捕获率等相对指标依赖基准对齐修正（见 T09），生成报告时须复算；水下指标只依赖策略净值，不受影响。
5. **适用 / 不适用条件**：例如「适合作为低 beta 卫星仓，不适合替代沪深300 做核心仓」。
6. **结论的可证伪点**：列出 2–3 个一旦出现就应推翻结论的信号（如成本 >16bp 后 IR 转负、子区间收益反转）。

### C2 策略解剖（What it is）

目的：让读者在看数字前，先知道这台机器由哪些齿轮组成。

- **决策链图**：市场状态 → 风险预算 → 候选池（趋势 + 反转）→ 相关性去重 → HRP 配权 → 跨资产腿（纳指/黄金）→ 防守仓 → 整组迟滞 → 组合波动上限 → 目标权重 → T+1 执行。每个环节标注：输入、规则、参数、输出、失败/降级行为。
- **参数表**：按层分组（趋势/反转/市场状态/去重/多资产/风险/防守/执行/成本/池子），列：参数、当前值、作用、是否默认、敏感性结论（平台/悬崖/不显著）。
- **合格池时序**：每日合格标的数量 + 类别构成（风险/债券/货币），说明池子是时变的。
- **机制 ↔ 研报假设映射表**：H1–H10 每条「已落地 / 简化 / 未复现」，以及对应影响。
- **执行口径示意**：T 日信号 → T+1 开盘成交；高开 ≥1% 顺延、停牌跳过；与 close 口径的差别。

### C3 决策审计（Why）★

目的：这是「为什么这样调仓」的主体，必须支持**任意一天**的追溯，而不是只讲三个故事。

- **事件表**（全量，可筛选/排序/导出）：日期、事件类型（换仓 / 过热清零 / 波动上限缩放 / 防守重选 / 跨资产腿切换）、当日 regime、换手、前三大权重变动、触发规则、事后 5/20 日收益（标注事后）。
- **事件详情卡**：选中某日后展示五步链路
  1. 市场状态：comp_score、regime、创业板趋势与波动；
  2. 风险预算：risk_scale × vol_scale_risk → risk_budget；
  3. 候选池：候选数、得分排序、去重保留、剔除原因；
  4. 规则改写：过热清零名单、跨资产腿权重、防守仓、迟滞是否维持；
  5. 结果：目标权重 vs 实际成交、当日逐笔成交与费用。
- **联动时间轴**：regime 色带 + comp_score + risk_budget + 总仓位/现金 + 回撤 + 事件标记，共享 x 轴，可选区间联动其他图。
- **候选池快照**：任一日 top 30 候选的 score/rank/是否保留/剔除原因。
- **单标的信号图**：m21/m60、score、zbias、close vs llt80（过热阈值线）、weight、status，事件点打标。
- **案例簿**：4–6 个代表性决策（牛市切换、2022 防守、过热清零、迟滞维持省下的换手、跨资产腿退出、五相位分批），每个案例 = 背景 + 触发信号 + 规则动作 + 结果 + 事后评价。
- **全量决策日记表**：24 列可筛选，作为审计底稿。

### C4 绩效（How much）

- 净值（线性/对数切换）+ 关键事件标记
- 水下曲线（underwater）+ 回撤区间阴影
- 回撤事件表：峰值日、谷底日、修复日、深度、持续天数、修复天数
- 年度表：收益、波动、Sharpe、最大回撤、换手、费用、年末仓位
- 年 × 月收益表（必须给数字，不只热力图），含年度合计与月度均值
- 滚动 252 日收益 / Sharpe
- 日收益分布 + 正态拟合 + 偏度/峰度
- （P2）QQ 图与尾部统计

### C5 风险（What risk）

- 滚动波动（20/60/252）+ 目标线（组合 34%、风险腿 26%、纳指/黄金 18%）
- 滚动 beta / 相关 vs 沪深300（252 日）
- 上下行捕获、月胜率
- 回撤期归因：选 5 个最深回撤区间，各资产类别/标的的贡献
- 集中度：HHI、有效持仓数、top5 权重
- 仓位与现金时序
- （P2）极端日表：top 10 涨跌日 + 当日持仓/状态/贡献

### C6 相对沪深300（vs benchmark）

- 累计超额曲线（几何）+ 超额回撤
- 滚动 252 日超额 / 滚动 IR
- 分年超额柱状
- 月度超额分布 + 月胜率
- 相对指标表（超额、TE、IR、beta、相关、上下行捕获）
- **对齐自检**：策略 vs 基准收益的 lag ∈ [−5, +5] 相关系数柱状，峰值必须落在 0；若不在 0，报告顶部必须标红并说明原因

### C7 归因与暴露（Where from）

- 资产类别累计贡献（风险/纳指/黄金/防守/现金），并注明「各项之和 = 组合日收益（不含现金利息）」
- 分年类别贡献（堆叠柱）
- 类别暴露时序（堆叠面积）
- 成本拖累：分年费用、费用占收益比、盈亏平衡成本
- 市场状态条件表现：牛/熊/震荡下的年化、胜率、平均仓位
- 剔除防守仓后的相关性与 beta（回答「低相关是不是债券仓位造成的」）
- top 贡献标的（前 15）+ 各自交易次数与持有天数

### C8 执行与交易（How executed）

- 目标 vs 实际权重偏差时序（平均绝对偏差、最大值）
- 换手分解：换仓 / 过热 / 波动缩放 / 防守重选 各占多少
- 顺延与停牌次数表（时间、标的、原因）
- 交易明细表：日期、标的、方向、价格、数量、金额、费用、占净值比
- 持仓明细表：每日 top N + 权重 + 状态标签
- 订单级路径：某日五相位分批成交的时间与价格
- 单笔往返：持有期、已实现盈亏、进出场原因分布
- 成本表：年均费用 bps、单笔均值/中位数、费用占毛利比
- （P2）滑点：成交价 vs 当日 open/close
- （P2）容量：按给定资金规模估算清仓天数

### C9 稳健性与可信度（Should I believe it）

- 数据质量：池子规模、退市数量、分类计数、覆盖与缺口、生存偏差处理方式
- 成本阶梯表 + 图（0/8/16/24bp）
- 子区间表（2019–2023 / 2024–2026）+ 一致性判断
- 机制消融表（baseline / 五个机制 off）：年化、回撤、Sharpe、Calmar、换手，并给增量方向
- 单参数敏感性：每个参数的网格曲线，标注平台区与悬崖点
- DSR / Sharpe haircut 表 + 一句人话解释（当前 0.54–0.55，低于 0.95 门槛，不作为显著性结论）
- 二维热力图（corr × cost）或链接
- 假设敏感性（H1 时间权重、H7 纳指退出阈值）对照
- 与研报差距对照表：20.74% / −10.13% / 2.05 vs 当前，逐条列可能原因（执行口径、成本、universe、复权、机制简化）
- **已知问题清单**（必须诚实列出，当前至少包含）：
  - 基准序列滞后一天（已记录，修复前所有日频相对指标不可用）；
  - 34% 组合波动目标几乎不触发；
  - `market_state_timeline` 的 bear 阈值线硬编码 −0.30（实际 −0.35）；
  - 「换仓」标记含 warmup/无持仓日；
  - 震荡市 score 量级减半（权重不变）。

## 6. P0 图表的详细说明

### V03 净值 + 回撤

- 画什么：上图为策略净值（可切对数轴），下图为回撤百分比；共享 x 轴；标注最大回撤的峰、谷、修复三点；事件标记来自 D01。
- 怎么读：看斜率（收益）、看回撤的深度与宽度（时间），不要只看最低点。
- 必须标注：CAGR、最大回撤、修复日期、当前是否在水下。
- 常见误读：把「回撤浅」当成「风险低」——还要看水下时长（P02）。

### D01 调仓事件表

- 每行一个事件，不是每天一行。事件类型：换仓（`hysteresis_held=False` 且有权重变化）、过热清零（`n_overheat_exits>0`）、波动上限缩放（`vol_cap_scale<1`）、防守重选、跨资产腿权重变化。
- 列：日期、类型、regime、当日换手、前三大权重变动（标的 + Δw）、触发规则、事后 5/20 日收益（标注事后）。
- 怎么读：先按换手排序看最大动作，再按类型筛选看规则是否按设计工作。
- 必须能跳转：任一行 → D03 详情卡。

### D03 事件详情卡

- 五步链路，每步显示「输入 → 规则 → 输出」：
  1. 市场：comp_score、regime、创业板趋势/波动、阈值；
  2. 预算：risk_scale、vol_scale_risk、risk_budget；
  3. 候选：n_cands、top 得分、去重后 n_kept、被剔除标的与原因；
  4. 改写：过热名单与 overheat_ratio、纳指/黄金权重、防守名单、迟滞 new/old score 与 2% 门槛；
  5. 结果：目标权重、实际成交、费用。
- 必须标注：信号日与成交日（T / T+1），避免误读为同日。
- 结论要求：读者能指出「这一天是哪条规则改变了结果」。

### D04 联动时间轴

- 轨道从上到下：regime 色带、comp_score（含 ±0.30/−0.35 线）、risk_budget、总仓位与现金、回撤、事件标记。
- 共享 x 轴；框选区间后其余图（P01/P02/R01/D06）同步过滤。
- 必须标注：regime 判定阈值、事件类型图例。

### P02 水下曲线

- y = nav / 历史峰值 − 1，面积填充；回撤区间用浅色分隔。
- 必须标注：最长水下天数（当前 596）、水下时间占比（当前 92.3%）、修复日。
- 怎么读：宽度比深度更能解释「为什么持有人会放弃」。

### B06 对齐自检

- lag ∈ [−5, +5] 的相关系数柱状图，峰值必须落在 0。
- 若峰值不在 0：报告顶部红色警示，写明「基准日期错位 N 天，所有日频相对指标不可用」。
- 这是可信度章节的入口检查，不能省略。

### A01 / A02 类别贡献

- A01 累计贡献（面积），A02 分年贡献（堆叠柱）。
- 必须写明：贡献 = Σ w_{i,t−1}·r_{i,t}，各项之和 = 组合日收益（不含现金利息）。
- 常见误读：把贡献当成「如果只持有该类资产的收益」——两者不同，需在图注区分。

### A06 剔除防守的相关性

- 两根柱：全样本 corr/beta vs 剔除防守仓后的 corr/beta。
- 目的：回答「低相关是不是债券仓位造成的」。
- 结论要求：若剔除后相关显著上升，判决里不能把「低相关」当作独立卖点。

### T04 机制消融

- 6 组：baseline、phases off、hysteresis off、reversal off、overheat off、vol_cap off。
- 指标：年化、最大回撤、Sharpe、Calmar、换手；用「相对 baseline 的增量」表达，避免读者自己减。
- 必须标注：哪几个机制在本样本几乎无影响（如 vol_cap），并说明原因（目标 34% 从未触发）。

### T05 单参数敏感性

- 每个参数一张小图：参数值 × Sharpe（或年化），标出默认值与候选值。
- 平台 = 邻域内指标平稳；悬崖 = 相邻取值指标断崖。
- 必须标注：稳健性分数、是否悬崖、DSR 是否显著。
- 结论要求：读者能判断「当前参数是平台还是孤岛」。

### X01 目标 vs 实际

- 平均绝对偏差（每日）+ 最大偏差；可下钻到单日单标的。
- 必须解释偏差来源：五相位分批、跳空顺延、停牌、整手取整。

### X07 单笔往返

- 按标的配对买卖，算持有期、已实现盈亏；分布图 + 明细表。
- 进出场原因来自 `ticker_signals.status` 与事件表；无法归因的标为「其他」。
- 结论要求：能区分「趋势跟随赚的钱」与「过热退出避免的损失」。
